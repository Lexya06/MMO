## Теоретическое введение в ООП для начинающих

### Ключевые концепции:
1. **Класс (`class`)** — это «чертеж» или шаблон, по которому создаются объекты.
2. **Объект (экземпляр / instance)** — конкретный представитель класса, созданный по его чертежу (например, класс `Car` — чертеж, а `my_car = Car()` — конкретный автомобиль).
3. **Статические переменные (атрибуты класса)** — переменные, определенные прямо внутри тела класса. Они общие для всех созданных объектов этого класса.
4. **Динамические переменные (атрибуты экземпляра)** — переменные, определенные через `self.имя_переменной` внутри конструктора `__init__`. У каждого объекта они свои собственные.
5. **Методы экземпляра (`instance methods`)** — функции внутри класса, первым параметром принимающие `self` (ссылку на конкретный объект).
6. **Методы класса (`@classmethod`)** — функции с декоратором `@classmethod`, первым параметром принимающие `cls` (ссылку на сам класс). Используются для фабричных методов и изменения параметров класса.
7. **Статические методы (`@staticmethod`)** — утилитарные функции внутри класса, не принимающие ни `self`, ни `cls`. Они не зависят от состояния объекта.
8. **Наследование (`inheritance`)** — создание дочернего класса на основе родительского (базового), перенимающего все его свойства и методы: `class Dog(Animal):`.
9. **Полиморфизм (`polymorphism`)** — возможность дочернего класса переопределить метод родительского класса по-своему (например, метод `show_speed()`).
