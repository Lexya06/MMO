### Теоретическая справка: как работает блок `try-except-else-finally`
```text
┌────────────────────────────────────────────────────────┐
│                        try:                            │
│           (Блок потенциально опасного кода)            │
└──────────────────────────┬─────────────────────────────┘
                           │
             Была ошибка? ─┴─ Нет ошибок?
             │                           │
             ▼                           ▼
┌──────────────────────────┐  ┌──────────────────────────┐
│         except:          │  │          else:           │
│  (Перехват и обработка   │  │  (Выполняется ТОЛЬКО     │
│   конкретного сбоя)      │  │   при успехе в try)      │
└────────────┬─────────────┘  └────────────┬─────────────┘
             │                             │
             └──────────────┬──────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│                      finally:                          │
│      (Гарантированно выполняется ВСЕГДА в конце)       │
└────────────────────────────────────────────────────────┘
```

## Задание 3: Поиск индексов первого вхождения максимума в матрице (2 балла)

### Условие
> Найдите индексы первого вхождения максимального элемента в двумерном массиве.  
> Выведите два числа: номер строки и номер столбца, в которых стоит наибольший элемент.  
> Требование: использовать функции и блок `try/except/finally`.

### Теоретическая справка для новичка
- Двумерный массив (матрица) в Python моделируется как «список списков»: `matrix = [[1, 2], [3, 4]]`.
- `matrix[i][j]` означает элемент в $i$-й строке и $j$-м столбце.
- Для поиска **первого** вхождения максимума используется строгое неравенство `val > max_val`. Если встретится такое же максимальное значение позже, оно не перезапишет координаты первого найденного.

### Построчный разбор кода (`part2.py`, строки 225–261)

```python
225: def find_first_max_index(matrix: list):
230:     try:
231:         if not isinstance(matrix, list) or len(matrix) == 0:
232:             raise ValueError("Матрица должна быть непустым списком списков!")
233: 
234:         if not all(isinstance(row, list) and len(row) > 0 for row in matrix):
235:             raise ValueError(
236:                 "Все строки матрицы должны быть непустыми списками!")
```
- **Строки 231–236:** Проверка на корректность структуры данных: матрица не должна быть пустой, и каждая ее строка обязана быть списком.

```python
239:         max_val = matrix[0][0]
240:         max_row = 0
241:         max_col = 0
242: 
243:         # Поиск максимального элемента (первого вхождения)
244:         for i, row in enumerate(matrix):
245:             for j, val in enumerate(row):
246:                 if not isinstance(val, (int, float)):
247:                     raise TypeError(
248:                         f"Элемент [{i}][{j}] = '{val}' не является числом!")
249:                 if val > max_val:
250:                     max_val = val
251:                     max_row = i
252:                     max_col = j
253: 
254:         return max_row, max_col, max_val
```
- **Строки 239–241:** Инициализация начального максимума самым первым элементом матрицы `matrix[0][0]`.
- **Строки 244–252:** Двойной цикл `for i, row ... for j, val ...` обходит все ячейки.
- **Строка 249:** Условие `if val > max_val:` обновляет максимум только если текущее число **строго больше** предыдущего. При дубликатах сохранятся координаты самого первого появления.
